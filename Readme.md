## 🧠 About me

I started as a web developer at Pansuriya Infotech in 2018, have worked independently with clients since 2021, and since 2025 my work has centred on AI.

Today I spend most of my time on:

- 🧪 **LLM evaluation** – rating and ranking model responses for accuracy, helpfulness, safety and instruction-following against detailed rubrics
- ✍️ **Training data** – writing and reviewing prompt–response pairs for fine-tuning, especially Python, JavaScript and TypeScript coding tasks
- ⚖️ **Preference ranking** – pairwise (A/B) comparisons with written justification for every judgement
- 🤖 **Agentic AI & RAG** – tool-calling agents and document chatbots for client products

My full stack background is my edge in evaluation work: I don't just check if a model's code *sounds* right — I run it, test edge cases and find the bugs.
